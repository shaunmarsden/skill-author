# Worked Example

Fictional scenario: authoring a skill for first-pass support ticket triage, then self-testing it.

- [inputs.md](inputs.md): the task, what a good result looks like, and what the AI must never do, gathered as [SKILL.md](../SKILL.md) asks for
- [generated-skill.md](generated-skill.md): the actual, complete skill produced from those inputs, a real, usable file, not a description of one
- [self-test.md](self-test.md): four fictional tickets, including two deliberate tone-versus-urgency traps in opposite directions and one genuinely ambiguous category, run through the generated skill
- [review.md](review.md): whether the generated skill actually had real guardrails, and whether it held up against the traps

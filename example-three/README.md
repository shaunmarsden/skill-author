# Worked Example Three: Someone Else's Skill

The first [example](../example/) writes a new skill and the [second](../example-two/) refuses a task that should never be one. This one goes the other way: it reviews a skill someone else wrote, one that its own page lists as widely installed, using the [review checklist](../checks/checklist.md).

The skill is `find-skills`, from Vercel's [vercel-labs/skills](https://github.com/vercel-labs/skills) repository. It helps an AI agent search for other skills and install them. The repository is MIT licensed. I read `skills/find-skills/SKILL.md` as it stood on 14 October 2026, when its last change was commit `773fb2c` of 10 July 2026. I didn't install it and I didn't run the `npx skills` tool.

- [inputs.md](inputs.md): the scenario I used to run the skill once, with made-up search results
- [review.md](review.md): the checklist applied to the skill, what the runs showed and what I couldn't check

This isn't a verdict on Vercel's tool. It's what the checklist finds when you apply it to a skill you didn't write, and where the checklist ran out.

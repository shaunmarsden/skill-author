# Worked Example Two: A Harder Case

The first [example](../example/) tests whether a generated skill's guardrails actually hold up. This one tests something more fundamental: whether the tool recognises a task that should never become a skill at all, no matter how it is framed.

- [inputs.md](inputs.md): a request specifically framed as wanting "a bounded, well-guardrailed skill" for an irreversible, high-stakes decision about real people
- [output.md](output.md): the response, which refuses to author a finished skill and offers a genuinely safer alternative instead
- [review.md](review.md): whether the refusal was for the right, specific reason, not a generic deflection
